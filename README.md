# 🍺 Homebrew Tap for debim (Declarative BIM)

Official Homebrew tap for [debim](https://github.com/PRIDA-TAKON/debim) — A minimal, Git-native, declarative BIM compiler & MCP Server for AI agents and humans.

---

## 🚀 Installation on macOS

### Option 1: One-liner install
```bash
brew install PRIDA-TAKON/debim/debim
```

### Option 2: Tap repository and install
```bash
brew tap PRIDA-TAKON/debim
brew install debim
```

---

## ⚡ Verification

```bash
debim --version
debim --help
```

---

## 🔄 Upgrade

```bash
brew update
brew upgrade debim
```

---

## 🗑️ Uninstall

```bash
brew uninstall debim
brew untap PRIDA-TAKON/debim
```
